Intro · 개념 정의

바이브코딩의 본질: 나만의 AI 직원 온보딩

바이브코딩은 단순히 질문에 답을 얻는 검색이 아닙니다. 내 PC에 상주하며 명확한 ‘업무 지시(프롬프트)’에 따라 결과물을 알아서 구축하는 전담 개발자를 두는 것입니다.

오늘 우리의 유일한 목표는 이 천재 직원이 스스로 일할 수 있는 완벽한 업무 환경(Workspace)을 세팅하는 것입니다.

BEFORE
검색형 AI
답변만 제공 · 실행은 사람의 몫 · 매번 수동 개입
AFTER
상주형 AI 직원
지시 → 구축 · 배포까지 자동 수행 · 사람은 방향만 결정

GitHub (소스 코드 금고)

Public
공개 · 기본값 주의
Private
비공개 · 권장 설정
역할

내가 만든 앱의 모든 코드와 수정 이력이 안전하게 보관되고 버전이 관리되는 온라인 저장소입니다. 구글 계정 연동으로 간편하게 가입합니다.

보안 핵심 꿀팁

직원이 코드를 업로드할 때 기본값이 Public(공개)일 수 있습니다. 나만의 아이디어가 유출되지 않도록 반드시 지시하세요.

PROMPT
“혹시 깃허브에 퍼블릭으로 반영되어 있으면 프라이빗(Private)으로 바꿔줘.”
  • 구글 계정 연동 가입 → 30초
  • 업로드 직후 공개 범위 한 번 더 확인

Infrastructure 03

Supabase (유저 데이터 그릇)

역할

회원가입, 로그인, 설문조사 등 사용자의 입력을 실시간으로 저장하고 관리해야 하는 ‘진짜 앱’을 만들 때 필수적인 데이터베이스입니다.

회원가입 로그인 설문 · 기록
2
무료 프로젝트 한도
회원가입 후 생성 가능 개수
무료 사용 구간추가 생성 시 유료
과금 주의사항
  • 회원가입 후 생성되는 무료 프로젝트는 최대 2개입니다.
  • 비밀번호 설정, 리전(Region) 선택 등 복잡한 프로젝트 생성 과정은 스킵해도 무방합니다.
  • API 키 결제 유도 창이 뜨면 일단 무시하고 진행하세요.
지금 단계의 목표는 계정 생성까지. 세부 설정은 AI 직원이 처리합니다.
